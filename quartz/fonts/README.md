# Chinese social-card font

Noto Sans CJK SC Regular is bundled for deterministic Chinese glyph rendering in the Open Graph image generator. It is used only during the build, not shipped as a site font.

Source: https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf
