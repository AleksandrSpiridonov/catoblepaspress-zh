# Китайская версия: первый этап

Исходник: русский репозиторий, коммит `1f646ad4cc05599cafb02c64661636e4a38cfbf8`.

Первая версия использует упрощённый китайский (`zh-CN`). Бренд остаётся Catoblepas. Китайские названия книг служат переводом для каталога, а не обещанием китайского издания.

## Объём первого этапа

- Перевести главную, об издательстве, контакты, все пять карточек книг и семь страниц разделов.
- Перевести интерфейс, подвал, просмотрщик, подписи таблиц и карточек.
- Сохранить все 74 Markdown-страницы, пути и медиа. Непереведённые страницы пометить как русские оригиналы; не выдавать их за китайский перевод.
- Проверить китайский поиск, навигацию, мобильную вёрстку и отсутствие русской аналитики.
- Подготовить адрес GitHub Pages с префиксом `/catoblepaspress-zh`, без изменения DNS и публикации на Fair.
- Не публиковать сайт в рамках первого локального этапа.

## Редакционные ограничения

Переводы — редакционный черновик; перед публичным запуском нужна вычитка носителем китайского. Даты, цены, имена и ссылки перенесены из указанного русского снимка, не являются новым подтверждением текущих условий. Стоимость международной доставки не установлена. Русские документы и внешние формы остаются явно обозначенными русскоязычными источниками.

## Далее

Перевести авторские страницы, клубы и их архивы, интервью, выпуски журнала, прочие публикации и документы отдельными партиями. Сохранять авторские строки стихов и исходные медиа. После редакционной проверки отдельно согласовать публикацию и конечный домен.

Генерация индивидуальных OG-картинок временно отключена: потребуется отдельно подобрать и проверить CJK-шрифт для серверного рендера. Используется существующее общее изображение. Рабочий процесс публикации из русского репозитория пока не адаптирован и не запускался.

## Проверка первого этапа

- `node quartz/bootstrap-cli.mjs build --concurrency=1` — успешная сборка.
- `node tools/verify-zh.mjs` — 15 китайских страниц, их внутренние ссылки и якоря, canonical с префиксом, русская пометка, отсутствие CNAME и Яндекс Метрики, отдельный возрастной экран.
- `npx tsc --noEmit` и `npm test` — проверка типов и полный набор тестов.
- Браузер: поиск «斜裁», переход к русскому автору и обратно со сменой `html.lang`, мобильная ширина 390 CSS px без горизонтального переполнения, возрастной экран.
- Медиа и исходные Markdown-пути сохранены; русские URL-псевдонимы и якоря карточек книг сохранены для старых ссылок.

Локальный просмотр: `node tools/preview-zh.mjs`, затем `http://127.0.0.1:8093/catoblepaspress-zh/`.
