## Публикация

GitHub Pages через Actions из main. Домен задаётся в quartz.config.yaml и генерируемом CNAME. Рабочий процесс .github/workflows/deploy.yml проверяет типы, тесты, сборку и китайские страницы перед загрузкой артефакта и деплоем. Публикации на Fair нет. Обязательный Site CI продолжает работать на PR и main.

## Проверки

- npm run install-plugins
- npx tsc --noEmit
- npm test
- node quartz/bootstrap-cli.mjs build --concurrency=1
- node tools/verify-zh.mjs

Проверка китайских страниц охватывает canonical, внутренние ссылки и якоря, CNAME, маркировку русских оригиналов, отсутствие Яндекс Метрики и отдельный возрастной экран. Ранее в браузере проверены поиск «斜裁», мобильная ширина 390 CSS px и смена html.lang при переходах.

## Ограничения и следующий этап

Переводы остаются редакционным черновиком и требуют вычитки носителем. Даты и цены перенесены из указанного русского снимка. Международная доставка требует уточнения у издательства. Внешние формы и правовые документы пока русскоязычные.

Индивидуальные OG-картинки временно отключены до проверки CJK-шрифта; используется существующее общее изображение. Следующие партии: авторы, клубы и архивы, интервью, журнал, публикации и документы.
